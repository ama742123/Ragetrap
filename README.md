# RageTrap

A mobile-friendly, browser-based rage platformer made with HTML, CSS, and JavaScript. It is designed to run on GitHub Pages without a server.

## Included

- 100 levels × 3 stages = 300 stages
- Increasing difficulty, spikes, moving hazards, crumble platforms, and surprise traps
- Touch controls and keyboard controls
- Synthesized sound effects for jumps, traps, deaths, stage clears, and the final victory (toggle with the SFX button; no external audio files needed)
- Level selection and stage progression
- Progress and death count saved locally in the browser (`localStorage`)
- Responsive home screen and instructions

## Upload from an Android phone

1. Open your GitHub repository in Chrome and sign in.
2. Open the repository where you want RageTrap.
3. Tap **Add file** → **Create new file**.
4. Create these three files in the repository root:
   - `index.html`
   - `style.css`
   - `game.js`
5. Copy the matching contents from this project into each file and commit the changes.
6. Open **Settings** → **Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Choose branch `main` and folder `/(root)`, then save.
9. Wait for the Pages deployment to finish. Your game link will be shown in the Pages section.

If GitHub Pages is already enabled, committing the files to the published branch should trigger a new deployment automatically.

## Controls

- Move: on-screen ◀ ▶ buttons; keyboard A/D or left/right arrows
- Jump: on-screen JUMP button; keyboard Space, W, or Up arrow
- Reach the green exit gate to clear a stage.

## Progress and privacy

Progress is stored in the browser on the device that plays the game. It is not synced across devices and can be erased if browser data is cleared. No account or server is required.

## Notes

This is a playable starter game with procedurally generated stages. Because layouts are generated by code, test and tune gameplay on the target phone. Browser audio may require a tap before sound plays.
